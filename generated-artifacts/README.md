# Generated Artifacts

Store representative Python and Java artifacts generated from ML2++ models, together with the source model, generator revision, dependencies, commands, and model-to-artifact trace information.

Chapter 5 technical-validation evidence is available under [`chapter5-technical-validation/`](chapter5-technical-validation/). It contains the six executed ML2++ model instances and the retained text-based run evidence used for the dissertation's Chapter 5 technical validation.
