# Step 1 — Manual Coding

This directory contains public, source-oriented packages prepared from the Stage-1 manual-coding material supplied for Study 1.

Files are organized by participant ID:
- `participant_01_source.zip`
- `participant_02_source.zip`
- `participant_03_source.zip`
- `participant_04_source.zip`
- `participant_05_source.zip`

Each ZIP includes a `MANIFEST.json` describing the source files retained in the public package and entries omitted from it. Participant-identifying file and folder names were normalized before publication.

The source-oriented packages retain reproducible material such as notebooks, scripts, ThingML/Java source where present, configuration/build files, small supporting CSV files, and participant text notes. Screenshots, PDFs, trained-model binaries, HTML capture assets, and large duplicate datasets are not republished in these packages. Validated shared datasets remain under the repository's `datasets/` directory.
