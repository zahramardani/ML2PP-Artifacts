# Full upload status

The Stage-1 manual-coding material supplied in this chat was checked and organized under participant IDs before publication.

Published source packages:
- `participant_01_source.zip`
- `participant_02_source.zip`
- `participant_03_source.zip`
- `participant_04_source.zip`
- `participant_05_source.zip`

The public packages retain source-oriented evidence such as notebooks, scripts, ThingML/Java source where present, configuration/build files, small supporting CSV files, and participant text notes. Each ZIP contains a `MANIFEST.json` describing included and omitted entries.

The supplied archives also contain screenshots, PDFs, generated/model binaries, HTML capture assets, and in some cases large datasets. These are recorded in the package manifests rather than silently treated as source evidence. Large validated datasets already represented under `datasets/` were not duplicated.

Participant-identifying names in public paths were normalized to participant IDs.
