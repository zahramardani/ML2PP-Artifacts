# Step 3 — ML2++ integration

This directory contains the Stage-3 ML2++ artifacts for Study 1. Participant-identifying filenames are not used in this public deposit.

## Participant models

The `participant-models/` directory contains the ML2++/ThingML model source recovered from the supplied Stage-3 participant packages:

- `participant_01_model.thingml`
- `participant_02_model.thingml`
- `participant_03_model.thingml`
- `participant_04_model.thingml`
- `participant_05_model.thingml`

These files preserve the model/code evidence relevant to participants working with ML2++. Screenshots and questionnaire PDFs contained in the supplied archives are not duplicated here as Stage-3 source artifacts; questionnaire evidence is maintained separately in the study replication package.

The previously deposited generated Stage-3 source tree remains in this directory. See `ARCHIVE_FORMAT.md` for the archival note.
