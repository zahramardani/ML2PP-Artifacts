# Step 2 - IoT integration

This directory contains de-identified source artifacts from the second participant-study task: IoT integration.

## Packages

- `participant_02_source.zip`
- `participant_03_source.zip`
- `participants_04_06_source.zip`

Participant IDs are anonymized study identifiers, not participant names.

## Included

- sensor/client code
- ingestion/server code
- analytics services
- offline-training scripts
- small helper modules required by the source

## Excluded from public deposition

- participant names and identifying filenames
- filled questionnaires and raw participant responses
- user-study PDFs
- screenshots
- tutorial/reference PDFs
- trained-model binaries and serialized model/scaler files
- duplicated datasets

`stage3_ml2.zip` is not included here because it belongs to the subsequent ML2++/ML integration stage rather than Step 2.
