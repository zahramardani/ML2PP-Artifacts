# Stage 4 Quick-Start study

This directory is the navigation page for the Stage 4 guided Quick-Start study reported in Chapter 6 of the dissertation.

## Tutorial used in the study

The public tutorial used by participants is archived here:

- [Stage 4 Quick-Start tutorial (PDF)](../../questionnaires/stage4_quick_start_tutorial.pdf)

The tutorial contains 13 guided tasks for the ML2++ editor and uses a prepared Tejo river-flow model. The named time series are Fratel, Castelo de Bode, and Almourol, with Almourol as the forecasting target.
