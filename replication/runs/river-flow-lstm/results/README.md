# Numerical results required

Each completed run should include:

- machine-readable aggregate metrics;
- absolute and relative baseline comparisons where reported;
- horizon-wise predictions and errors;
- the exact test targets paired with predictions;
- generated figures or the scripts and data needed to recreate them;
- random seeds and split indices; and
- the complete execution log.

Values transcribed from a thesis table are documentation, not a substitute
for the original prediction and metric files.
