# Generated artefacts required

Archive the unmodified output of the pinned ML2++ generator for each run,
including preprocessing, training, prediction, evaluation, visualization,
and runtime-integration sources where applicable.

Do not silently correct a generated file. If a correction is necessary,
preserve the generated original and store the correction separately as a
patch or reference implementation with an explicit provenance label.
