# Data-protection boundary

The public package may include questionnaire instruments, anonymised aggregate
statistics, analysis code and consent-compatible de-identified data.

Do not publish participant names, email addresses, raw identifiers, session
recordings, private free-text answers or participant-level logs unless the
consent materials and applicable data-protection requirements explicitly
permit public release. Stage 4 collected a full-name field; that field must be
excluded from any public analysis table.

For restricted study data, publish a data dictionary, filtering rules,
aggregation logic and a controlled-access procedure instead of the raw file.
