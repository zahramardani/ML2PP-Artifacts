# Raw participant material and access boundary

The completed participant forms are not included in this public repository.

The source archive contains participant-level responses, free-text answers,
document metadata, duplicate scans, rendered page images, and nested archives.
Publishing those files would create avoidable re-identification and data-
protection risk, even where names are absent from the visible questionnaire.

The public package therefore contains only de-identified variables already
reported in the dissertation. Consent to participate in the study is not treated
as automatic consent for unrestricted public release of raw individual forms.

A future controlled-access release would require:

1. confirmation that the consent language permits the intended reuse;
2. institutional data-protection/ethics review where required;
3. removal of direct and indirect identifiers, metadata, and signatures;
4. review of free text for re-identification risk;
5. a documented access request and data-use process.

Researchers can reproduce the published descriptive tables from
`participant_profiles.csv`, `effort_and_completion.csv`, and
`stage3_results.csv` without access to the raw forms.
