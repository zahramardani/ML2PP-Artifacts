# ML2++ overview

ML2++ is a model-driven engineering approach for specifying and automating time-series forecasting workflows in IoT and cyber-physical systems.

The work combines a domain-specific modeling language, model validation, orchestration, and code generation. The textual modeling environment is based on Xtext and the graphical work includes Sirius Web.

The forecasting use cases include river-flow forecasting, smart-energy forecasting, and solar-power forecasting. Models used across the research include LSTM, GRU, ARIMA, Holt-Winters, XGBoost, and Prophet.

A key objective is to reduce repetitive implementation effort while keeping forecasting configurations explicit and reproducible. A model-driven workflow can capture forecasting choices such as inputs, target variables, lag configuration, forecast horizon, model family, and evaluation settings.
